================================================================
TROUBLESHOOTING
================================================================

PROBLEM: Server won't start (port 3055 in use)
SOLUTION: 
   netstat -ano | findstr :3055
   taskkill /PID <PID> /F
   sync.bat --server

PROBLEM: "FIGMA_ACCESS_TOKEN not set" error
SOLUTION:
   type .env  (check if file exists and has token)
   -- Create .env if missing:
   echo FIGMA_ACCESS_TOKEN=figd_YOUR_TOKEN > .env
   echo FIGMA_FILE_KEY=CXxUbHl3oMzt9Bzv3SKv75 >> .env

PROBLEM: WebSocket shows "🔴 Offline" in browser
SOLUTION:
   -- Server not running. Start it:
   sync.bat --server
   -- Then refresh browser

PROBLEM: Figma changes not detected after 30 seconds
SOLUTION:
   -- Run manual sync:
   node scripts/cli-sync.cjs --figma-to-code
   -- Check Terminal 1 for polling errors
   -- Verify FIGMA_ACCESS_TOKEN is valid

PROBLEM: Component deleted in Figma but folder still exists in code
SOLUTION:
   -- Run manual sync:
   node scripts/cli-sync.cjs --figma-to-code
   -- Check .sync-state.json for stale entries

PROBLEM: Git push fails
SOLUTION:
   cd "d:\HDFC\UI Components"
   git status
   git remote -v
   git push origin main
