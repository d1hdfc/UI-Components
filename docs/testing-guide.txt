================================================================
TROUBLESHOOTING
================================================================
Plugin shows "Disconnected"
  → Make sure sync.bat --server is running

Figma not updating after code change
  → Plugin panel must be OPEN in Figma to receive WebSocket messages
  → Check Terminal 1 shows [CodeWatcher] CHANGED log
  → Reload plugin if needed: Plugins > Development > Hot reload plugin

font-size not applied in Figma
  → Font (Inter) must be installed in Figma
  → Plugin loads fonts async — wait 2-3 seconds after sync

Build errors TS1351
  → Check src\components\index.ts for exports starting with a number
  → Run: node scripts\app-page-generator.cjs to regenerate

FigmaPoller "Polling check failed"
  → FIGMA_ACCESS_TOKEN may be expired — generate a new one at:
    https://www.figma.com/developers/api#authentication
